# Customer Segmentation using K-Means Clustering

Identified 5 distinct customer segments from retail data using K-Means clustering.

**Tools:** Python, pandas, scikit-learn, matplotlib, seaborn  
**Dataset:** Mall Customers (200 customers, 5 features)  
**Key result:** 5 segments identified — high-value, impulsive, budget-conscious, average, and untapped rich customers
